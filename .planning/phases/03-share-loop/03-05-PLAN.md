## Flagged Assumptions

**SHARE-03 — unresolved (`unclassified`).** No probe-derived edge set exists. Assumed edges covered
by this plan's gate behaviour: a checklist row with no matching attribute, an attribute removed from
code, a missing or empty checklist file, an unreachable base URL, and a canonical that gains a query
string. Surfaced here rather than dropped.

**Rendered-HTML assumption.** The share buttons and the awards panel render only after client-side
data loads, so a server-rendered HTML fetch of `/analyze/{code}` cannot see them. The gate therefore
asserts the attributes against tracked source files and asserts the route and canonical contracts
against live HTTP — the combination that is actually checkable without adding a headless-browser
dependency. This is a deliberate divergence from `seo-invariants.mjs`, which is purely live, and it
is recorded in the checklist's own enforcement section.
