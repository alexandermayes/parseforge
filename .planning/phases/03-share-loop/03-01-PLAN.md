<objective>
**As a** raider who just analyzed a log, **I want to** paste one link into my guild's Discord
**so that** the pull's awards unfurl as an image everyone can read without opening anything.

This is the phase tracer: the thinnest end-to-end path through every layer the awards feature
touches — pure engine, OG image render, SSR metadata forwarding — wired for real, with a real
fallback. After this plan a user who appends the awards view param to a report URL gets an
awards image in Discord. Plan 03-04 gives them the button; plan 03-02 fills the rule pool out.

Task 2 adds the small pure share-link module every later plan in this phase imports.

Purpose: prove the awards architecture end-to-end on one path before layers are committed on
top of it, and establish the single shared engine that the OG image and the in-app panel will
both read (the Phase 2 D-08 pattern).
Output: `lib/awards-engine.ts` (+ test), `lib/share-links.ts` (+ test), a `view=awards` branch
on the existing `/og` route, and `view` forwarding in `generateMetadata`.
</objective>
