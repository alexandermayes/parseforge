<objective>
Record the real Warcraft Logs rankings and rate-limit response shapes as committed fixtures, so that
R0-3's types and engine (04-04) are written against reality rather than against a document
(R0-2, `PARSEFORGE-RANKINGS-SPEC.md` §7).

**User story context:** this plan ships no user-visible change by design — D-13 keeps all rankings
work non-user-facing until the RPGLogs approval reply lands. What a real user gets at the end of the
phase is an analyzer that did not get slower; what this plan gets *them* is the guarantee that the
rankings lens built on top of it later will read WCL's actual numbers correctly the first time.

Purpose: Phase 2 already proved the value of recording before building — the Wave 0 fixture run
corrected a wrong assumption (A3) before any engine was written on it. R0-2 is the same move for
rankings, and it resolves 04-RESEARCH.md's A5 and A6 and both Open Questions.
Output: six committed `lib/__fixtures__/rankings-*.json` files, shape tests for each, provenance,
and a measured point-cost table.

**Already known before you start (verified this planning session, read directly from the committed
fixture — do not re-derive):** `lib/__fixtures__/demo-player-dps.json` already contains one
`reportData.report.rankings.data[0]` entry for the demo report/fight, whose top-level keys are
`fightID, partition, zone, encounter, difficulty, size, kill, duration, bracketData, deaths,
damageTakenExcludingTanks, roles, bracket, reportsBlacklistForCharacters, speed, execution`.
`roles` has `tanks` / `healers` / `dps`, each `{ name, characters[] }`, and each character carries
`{ id, name, server{id,name,region}, class, spec, amount, bracketData, bracket, rank, best,
totalParses, rankPercent }`. `speed` and `execution` are each `{ rank, best, totalParses,
rankPercent }`. `reportsBlacklistForCharacters` was an empty array in that recording, and **no
`hidden` field was present on any character** — which is itself a finding this plan must record,
because 04-04 has to honour `hidden` when present without assuming it always is.
</objective>
