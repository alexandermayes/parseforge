CMP, EEA/UK visitors keep the exact TCF gate, and the OPS-01 gate can never again pass on
pre-deploy data.

<objective>
Prove the fix in a real browser against a real deployment, before production.

The bug was found by a netlog, not by reading code, and the fix is confirmed the same way (D-10).

deployment's own `/api/geo` response, not inferred from a docs page that is silent on it.

OPS-01 gate document.
