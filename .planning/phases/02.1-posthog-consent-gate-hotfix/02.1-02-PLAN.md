## Phase Goal

Every visitor is measured again - non-EEA/UK visitors are captured without depending on the Google
CMP, EEA/UK visitors keep the exact TCF gate, and the OPS-01 gate can never again pass on
pre-deploy data.

<objective>
Make the gate a gate.

The outage ran for eight days behind two signed OPS-01 gates. Both signed honestly against the
checklist as written: item 4 asked whether the event *definition* appeared in PostHog, and an event
definition created weeks earlier is still there whether or not a single event has been ingested
since. The checklist's own recording rules already say a `no-data` row is never a pass - but no row
would ever have gone `no-data`, because nothing in the gate counted events.

This plan adds the row that counts events (D-08) and writes the honest correction into the two
verification records that signed without it (D-09). It touches no source code, so it runs in
parallel with the fix itself.

Purpose: ROADMAP success criterion 4 - the durable half of this phase.
Output: a hardened `docs/OPS-01-SHIP-GATE.md` Part 1, and dated append-only addenda in
`01-VERIFICATION.md`, `02-VERIFICATION.md` and `REQUIREMENTS.md`.
</objective>
