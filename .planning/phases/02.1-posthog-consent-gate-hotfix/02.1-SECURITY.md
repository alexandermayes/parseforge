|----------|-------------|---------------|
| Vercel edge → `/api/geo` | Vercel attaches `x-vercel-ip-country`; the route reads only that header | ISO country code (derived from client IP; not stored) |
| `/api/geo` → browser | Single boolean response, `private, no-store` | `{ isConsentRegion }` |
| Browser → PostHog (`/ingest/*`) | Capture and replay start only after the consent gate resolves (geo opt-in or TCF full opt-in) | Analytics events with `consent_gate_path`; session replay only on full opt-in |
| Google CMP (`__tcfapi`) → `lib/consent.ts` | Unchanged from Phase 1; consent-region visitors only | TCF consent signal |
| Developer machine → Vercel (`vercel deploy`) | Personal profile via `--global-config ~/.vercel-personal`; production only after an explicit in-session yes | Build artifact; preview bypass secret (never printed/committed) |
| Session → PostHog HogQL (MCP) → `docs/OPS-01-SHIP-GATE.md` | Aggregate counts only, `switch-project 337485` first | Country codes, gate-path values, counts |
