## Phase Goal

Every visitor is measured again - non-EEA/UK visitors are captured without depending on the Google
CMP, EEA/UK visitors keep the exact TCF gate, and the OPS-01 gate can never again pass on pre-deploy
data.

## User Story

**As a** developer whose six Phase 1 and Phase 2 custom events have never once been ingested,
**I want to** deliberately perform the interactions that fire them and watch them land in PostHog
with the right consent path attached, **so that** ROADMAP SC3 stops resting on "nobody happened to
click it during the measured hour" and starts resting on a counted observation.

<objective>
Close the automatable half of Gap A from `02.1-VERIFICATION.md` (Truth 5 / ROADMAP SC3, and Human
Verification item 3). The 2026-09-14 production window recorded 12 distinct event types ingesting -
an unambiguous restoration of capture - but every one of the six named events recorded 0, because
nobody toggled the theme and nobody opened the Timeline tab in that hour.

The gap's own `missing` clause accepts "a live-traffic window **or targeted manual test**". This
plan performs the targeted manual test: drive the four interactions against live production from a
non-consent-region egress, then query PostHog for the window and record what actually ingested,
with `consent_gate_path` attached.

Two of the six named events cannot be produced this way and that is stated up front rather than
discovered halfway: `consent_resolved` and `consent_unavailable` only exist on the consent-region
path, which the geo classifier never starts for a US visitor. They belong to 02.1-08.

No application source changes here. If a confirmed interaction produces no event, that is a defect
this plan surfaces and stops on - it does not patch it.

Purpose: ROADMAP SC3; OPS-01 instrumentation verified live rather than by event-definition
existence.
Output: a dated Part 4 section with the interaction log, the window bounds, the aggregate query, and
a per-event status line for all six named events.
</objective>
