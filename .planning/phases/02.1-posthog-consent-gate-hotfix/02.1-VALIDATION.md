## Sampling Rate

- **After every task commit:** Run the quick run command
- **After every plan wave:** Run the full suite command (+ `npm run lint` — total must not exceed the `main` baseline)
- **Before `/gsd-verify-work`:** Full suite green **and** D-10 preview netlog recorded **and** D-08 live-traffic HogQL evidence pasted into `docs/OPS-01-SHIP-GATE.md`
- **Max feedback latency:** 90 seconds
