<objective>
Deliver the DSGN-03 theme slice end-to-end: a visitor's OS preference decides the theme on
first visit (D-08), and a 3-state navbar control (Light / Dark / System, D-10) lets them
override it with a choice that persists across loads and routes — instrumented with a PostHog
`theme_changed` event (OPS-01).

Purpose: this is the phase's leading tracer. Every later plan in this phase (light palette,
domain colour tokens, hardcoded-value sweep) is only observable through this control, so the
architecture — class-attribute theming driven by `next-themes`, resolved before first paint —
must be proven and committed before any expansion work builds on it.

Output: `next-themes` installed, `app/components/ThemeProvider.tsx` and
`app/components/ThemeToggle.tsx` created, `app/layout.tsx` migrated off the hardcoded theme
class, `components/ui/dropdown-menu.tsx` pulled from the official shadcn registry.
</objective>
