  <action>
    Create `scripts/token-audit.mjs`, a plain ESM node script using only `node:` built-ins that walks
    `app/`, `components/` and `lib/` for `.ts` and `.tsx` files and reports two finding kinds:

    - **Kind `palette-class`** — a Tailwind palette utility: one of the utility prefixes
      (`text`, `bg`, `border`, `from`, `to`, `via`, `ring`, `fill`, `stroke`, `decoration`,
      `outline`, `divide`, `placeholder`) followed by a hyphen, one of Tailwind's built-in palette
      family names (`slate`, `gray`, `zinc`, `neutral`, `stone`, `red`, `orange`, `amber`, `yellow`,
      `lime`, `green`, `emerald`, `teal`, `cyan`, `sky`, `blue`, `indigo`, `violet`, `purple`,
      `fuchsia`, `pink`, `rose`), a hyphen and a two-or-three digit shade.
    - **Kind `raw-hex`** — a six-digit hex colour literal.

    Report each finding as `path:line: kind: matched-text`. Maintain an explicit allowlist, each
    entry carrying a `reason` string, seeded with:
    - `app/og/route.tsx` — whole file. Satori (`next/og`) is a static image renderer with no CSS
      engine and cannot resolve a custom property; this exception is already documented in the file.
    - Any declaration whose identifier ends in `_HEX` in `lib/constants.ts` — the Satori-only maps
      introduced in plan 01-05, for the same reason.
    An allowlist entry with an empty or missing reason must make the script exit non-zero: an
    unexplained exception is exactly the silent omission this gate exists to prevent.

    The script also reads `app/globals.css` and reports which `@theme` categories are declared,
    keyed by prefix: colour (`--color-`), radius (`--radius-`), font (`--font-`), spacing
    (`--spacing`), motion (`--duration-` and `--ease-`) and elevation (`--shadow-`). Report a
    category as absent when no matching declaration exists — DSGN-01 requires all four of colour,
    spacing, motion and elevation.

    Three modes:
    - default — print findings and the category inventory, exit 1 when there is at least one
      non-allowlisted finding or an absent required category
    - `--report` — print the same output, always exit 0
    - `--markdown <path>` — write a markdown report to `<path>` (creating parent directories) and
      exit with the same code as default mode

    Add `"token-audit": "node scripts/token-audit.mjs"` to `package.json` `scripts`.

    Run `npm run token-audit -- --report` and record the finding count and the per-file breakdown in
    the SUMMARY — that list is the worklist plan 01-07 drives to zero, and its non-emptiness now is
    the machine-proof that the gate has teeth.
  </action>
