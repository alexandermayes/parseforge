`__tcfapi`, and translate the result into the SDK's own consent API so that EEA/UK session replay
runs only after consent (D-05, D-06) while non-EEA visitors keep today's default-on behaviour
(D-07).

lands before any ad script exists.

tag in the SSR shell, and the report-only CSP extended with the CMP host.
</objective>
